# Capstone-Project: When We Bloom

This repository contains the source codes and documentation for my capstone project. The goal of this project is to see how natural gesture-based interaction communicate emotional ideas through physical and digital systems.

## Research Question
**"How can I create a playful, gesture-based interactive installation that evokes wonder, openness, growth, and vulnearbility through physical-digital systems ?"**

## Electrical Components
- Ultrasonic Sensor
- Servo Motor 
- Breadboad 
- Power Module with Battery (Exhibition: Refurbished old iMac as Power Supply w/ DC Voltage Step Down Converter from 12V to 5V)
- Jump Wire F/M (14AWG & 10AWG)
- Y-Splitter Cables
- RGB LEDs

(Yet to be incorporated)
- Audio Amplifier Module
- Speaker
